# Rishab Batra — Academic Portfolio

This is a simple HTML/CSS/JavaScript portfolio designed for GitHub Pages.

## Folder structure

portfolio/
├── index.html
├── style.css
├── script.js
├── images/
│   └── profile.jpg
└── documents/
    └── CV.pdf   <-- add your CV here

## Run locally

Double-click `index.html` to open the website in your browser.

For easier development, open the folder in VS Code and use the Live Server extension.

## Publish on GitHub Pages

1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload all files and folders from this portfolio.
3. Open the repository's Settings → Pages.
4. Select the `main` branch as the deployment source.
5. Save and wait for GitHub Pages to publish the site.
6. Your website will be available at `https://YOURUSERNAME.github.io`.

## Important

The View CV and Download CV buttons expect:

`documents/CV.pdf`

Add your actual CV PDF with exactly that filename before publishing.
